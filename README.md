# m5-w1-d1-demo: React In-Class Demos (Week 1 Day 1)

This repository contains the completed exercises for Westcliff University WEB 403/603 - Week 1 Day 1.

## Demos Overview

- **Demo 1:** Basic React CDN setup with `ReactDOM.render` displaying "Hello, world!".
- **Demo 2:** First React Component (`HelloMessage` extending `React.Component`) with props.
- **Demo 3:** Interactive stateful button (`LikeButton`) with `constructor` and `this.state = { liked: false }`.
- **Demo 4:** Timer Component with lifecycle methods (`componentDidMount`, `componentWillUnmount`) and interval updates, shown both with and without JSX (`timer.js` and `timer-jx.js`).
- **Demo 5:** JSX attributes and expression interpolation with `formatName(user)` function.
- **Demo 6:** Create React App (`my-app`) integrated with Bootstrap and Reactstrap Danger button.
- **Demo 7:** React inline styling (`style={{ color: "red" }}`).
